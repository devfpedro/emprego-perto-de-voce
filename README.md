# Emprego Perto de Você 📍

O **Emprego Perto de Você** é uma plataforma digital focada em conectar rapidamente candidatos a oportunidades de trabalho locais de forma simplificada e geolocalizada. O foco é atender pequenas e médias empresas que precisam preencher vagas com moradores da própria região ou bairro.

## 💻 Sobre o Projeto
Este  Produto Mínimo Viável (MVP) está sendo desenvolvido pela equipe **Iteravise** como parte da disciplina de Gerência de Projetos de Software (Curso de Sistemas para Internet). O projeto está sendo gerenciado utilizando metodologias ágeis (Scrum/Kanban) através do Jira, com ciclos semanais de entrega (Sprints).

## 🛠️ Tecnologias Utilizadas (Escopo Inicial)
* **Front-end:** React / React Native *(em definição)*
* **Back-end:** Node.js / Java Spring Boot *(em definição)*
* **Banco de Dados:** PostgreSQL
* **Gerenciamento:** Jira
* **Prototipação:** Figma
